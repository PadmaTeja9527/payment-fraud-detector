# Payment Fraud Detector

## Overview
This project uses Machine Learning to detect fraudulent payment transactions.

## Features
- Fraud detection using ML algorithms
- Data preprocessing
- Model training and evaluation
- Prediction on new transactions

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Structure
```
payment-fraud-detector/
│
├── data/
├── notebooks/
├── models/
├── app.py
├── requirements.txt
└── README.md
```

## Installation

```bash
git clone https://github.com/PadmaTeja9527/payment-fraud-detector.git
cd payment-fraud-detector
pip install -r requirements.txt
```

## Usage

```bash
python app.py
```
